# Azeri Game Shop

Это готовый код маркетплейса игровых аккаунтов Azerigame на React и Tailwind CSS. Восстанови этот интерфейс и функционал.

Наша следующая задача:

Сделай рабочую карусель/галерею скриншотов в карточке товара (чтобы покупатель мог листать фотографии аккаунта).

Настрой интерактивные фильтры по категориям игр на главной странице
